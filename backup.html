03 / Orientações

Como utilizar com segurança

Três cuidados importantes para seus registros.

ETAPA 01

Faça uma cópia

Antes de realizar alterações importantes ou restaurar informações, baixe uma cópia atualizada dos registros existentes.

ETAPA 02

Confira o arquivo

Selecione o arquivo JSON correto e utilize a opção de verificação para conferir as informações antes da restauração.

ETAPA 03

Confirme com atenção

A restauração pode substituir os registros atuais. Confira se a cópia selecionada corresponde aos dados que deseja recuperar.

!

Atenção antes de restaurar

A restauração substituirá os dados atuais de produtos, entradas, saídas e preços financeiros pelos registros contidos no arquivo selecionado, conforme as funcionalidades implementadas no backup.js. Outros módulos também poderão ser afetados caso estejam incluídos na rotina de restauração. Antes de continuar, faça uma cópia dos dados existentes.
