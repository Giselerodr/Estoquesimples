Importação de Produtos.

Cadastre vários produtos de uma só vez, analise os dados de uma planilha CSV e confira possíveis duplicações ou informações inválidas antes de confirmar.

Importação inteligente

Menos cadastros manuais.
Mais eficiência no estoque.

Utilize uma planilha para organizar os produtos, analisar as informações e realizar cadastros em massa com maior praticidade.

⇩
01 / Preparação

Baixar planilha-modelo

Prepare os dados para importação.

Modelo de cadastro

Prepare sua planilha CSV

Utilize o modelo disponibilizado pelo sistema para preencher os produtos no Excel ou em outro editor de planilhas. Não altere os nomes das colunas.

02 / Análise

Selecionar planilha

Carregue e analise o arquivo.

Leitura de arquivo

Importar arquivo CSV

Escolha um arquivo CSV preenchido. Ele deve conter nome, categoria, código, quantidade, estoque mínimo e validade dos produtos.

ETAPA 02
Arquivo de produtos
Configuração da importação

Na atualização, a quantidade informada na planilha será considerada o novo saldo do produto. As movimentações históricas serão preservadas.

Conferir produtos
